# Week 07, Topic 01: Library Management System - DDL & Basic DML

## Overview
This topic provides a hands-on exercise to practice DDL (Data Definition Language) and basic DML (Data Manipulation Language) by building a simple Library database from scratch. 

## Learning Objectives
*   Create tables using `CREATE TABLE`
*   Insert sample data using `INSERT`
*   Update records using `UPDATE`
*   Apply basic constraints such as `PRIMARY KEY`, `NOT NULL`, and `UNIQUE`.
*   Practice the concept of a "soft delete" by updating an `IsActive` column instead of deleting a row.

## Scenario
You will define the schema for two tables: `Books` and `Members`. After the tables are created, you will insert sample data. You'll also see how to update book availability and deactivate a member.
