# Week 8 Topic 5: Recommended Tools for Practice

## Overview
This folder provides a sandbox environment using Docker containers (PostgreSQL and pgAdmin). It is intended for safe experimentation and practice using the recommended tools for advanced database concepts.

## Recommended Tools for Practice
- **pgAdmin (Included here)** / **MySQL Workbench** / **SQL Server Management Studio**: Multi-query window support for concurrency testing.
- **DB Fiddle** or **SQLFiddle**: Online SQL editors for quick testing.
- **Docker containers (Used here)**: Spin up isolated database instances for safe experimentation.

## Practice Activities
- Use the included Docker setup to spin up an isolated PostgreSQL instance.
- Practice opening multiple query tools in pgAdmin to simulate concurrent users.
- Experiment freely knowing that you can easily tear down and recreate the environment.
