# Week 01: Data Types and Database Objects

This example illustrates the difference between structured, semi-structured, and unstructured data. It also introduces key database objects beyond basic tables, such as Views, Indexes, and Stored Procedures (Functions in PostgreSQL).

## Folder Structure

*   `docs/`: Contains explanations of the theoretical concepts (Data Types and DB Objects).
*   `init-scripts/`: Contains the SQL script that creates examples of different data types (including JSONB for semi-structured data) and creates a View, an Index, and a Function.
*   `docker-compose.yaml`: Runs the PostgreSQL database and pgAdmin interface.
*   `QUICKSTART.md`: Instructions on how to run the example and view the objects.
