# Schema Overview

## `Employees` Table

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `EmpID` | INT (Primary Key) | Unique identifier for the employee. |
| `FirstName` | VARCHAR(50) | The employee's first name. |
| `LastName` | VARCHAR(50) | The employee's last name. |
| `HireDate` | DATE | Date the employee was hired. |
| `Department` | VARCHAR(50) | The department they belong to. |
| `Salary` | DECIMAL(10, 2) | The employee's current salary. |
