# Theory: GROUP BY, HAVING, and Aggregate Functions

- **GROUP BY:** Used in collaboration with the SELECT statement to arrange identical data into groups. This `GROUP BY` clause follows the `WHERE` clause in a `SELECT` statement and precedes the `ORDER BY` clause.
- **Aggregate Functions:** Functions that perform a calculation on a set of values, and return a single value. These include `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`.
- **HAVING:** Used to place conditions where we need to decide which group will be the part of final result-set. Also, `HAVING` can be used with aggregate functions, whereas `WHERE` cannot be used with aggregate functions.
