# Week 00: Preparation for ITEC617

Welcome to the preparation week for ITEC617. Before we begin the unit, please ensure you have the necessary tools installed and configured on your machine.

## Tasks for this week:

1. **Install SQLite**: Learn how to install and run the SQLite command line interface. See [00.SQLite.md](00.SQLite.md)
2. **Install Docker and Databases**: Install Docker and set up MySQL and PostgreSQL containers. See [01.docker.md](01.docker.md)
3. **Basic SQL Queries**: Familiarize yourself with basic SQL commands by creating a database, tables, inserting data, querying, and creating views using SQLite and PostgreSQL. See [02.SQL-Queries.md](02.SQL-Queries.md)
4. **Database Tools**: Overview of DB clients, ERD tools, modeling tools, and AI-assisted options. See [03.Database-Tools.md](03.Database-Tools.md)
