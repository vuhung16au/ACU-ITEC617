# Basic SQL Queries: Create, Insert, Select, Delete, and Views

This guide illustrates fundamental SQL operations.

## The Scenario

We will create a simple database for a bookstore to manage authors and their books.

### 1. Create a Database

#### In SQLite:
You create a database file simply by specifying it when starting the CLI:
```bash
sqlite3 bookstore.db
```

#### In PostgreSQL:
Connect to your running Postgres instance (e.g., via Docker):
```bash
docker exec -it some-postgres psql -U postgres
```
Then, create and connect to the database:
```sql
CREATE DATABASE bookstore;
\c bookstore
```

### 2. Create Tables with Fields

Let's create two tables: `authors` and `books`.

```sql
-- Create authors table
CREATE TABLE authors (
    id INTEGER PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    country VARCHAR(50)
);

-- Create books table
CREATE TABLE books (
    id INTEGER PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    published_year INTEGER,
    author_id INTEGER,
    FOREIGN KEY (author_id) REFERENCES authors(id)
);
```
*(Note: In Postgres, `INTEGER PRIMARY KEY` works, but typically you might use `SERIAL PRIMARY KEY` for auto-incrementing. SQLite uses `INTEGER PRIMARY KEY` for auto-increment.)*

### 3. Insert Data

Let's populate our tables with some data.

```sql
-- Insert authors
INSERT INTO authors (id, name, country) VALUES (1, 'J.K. Rowling', 'UK');
INSERT INTO authors (id, name, country) VALUES (2, 'George R.R. Martin', 'USA');
INSERT INTO authors (id, name, country) VALUES (3, 'J.R.R. Tolkien', 'UK');

-- Insert books
INSERT INTO books (id, title, published_year, author_id) VALUES (1, 'Harry Potter and the Sorcerer''s Stone', 1997, 1);
INSERT INTO books (id, title, published_year, author_id) VALUES (2, 'A Game of Thrones', 1996, 2);
INSERT INTO books (id, title, published_year, author_id) VALUES (3, 'The Fellowship of the Ring', 1954, 3);
INSERT INTO books (id, title, published_year, author_id) VALUES (4, 'The Two Towers', 1954, 3);
```

### 4. Select Data

Retrieve data from the tables.

```sql
-- Get all authors
SELECT * FROM authors;

-- Get titles of books published before 1990
SELECT title, published_year FROM books WHERE published_year < 1990;

-- Get books with their author's name using a JOIN
SELECT books.title, authors.name 
FROM books 
JOIN authors ON books.author_id = authors.id;
```

### 5. Create a View

A View is a virtual table based on the result-set of an SQL statement. It's useful for simplifying complex queries that you run frequently.

```sql
-- Create a view that combines book titles and author names
CREATE VIEW book_details AS
SELECT b.title AS Book_Title, a.name AS Author_Name, b.published_year
FROM books b
JOIN authors a ON b.author_id = a.id;

-- Query the view just like a regular table
SELECT * FROM book_details;
```

### 6. Delete Data

Remove records from a table.

```sql
-- Delete a specific book
DELETE FROM books WHERE id = 4;

-- Verify the deletion
SELECT * FROM books;
```

## Running these scripts

- **SQLite**: You can copy and paste these commands directly into the `sqlite>` prompt after running `sqlite3 bookstore.db`.
- **PostgreSQL**: You can copy and paste these commands into the `postgres=#` prompt after connecting to your database using `psql`.
