# Installing and Running SQLite

SQLite is a C-language library that implements a small, fast, self-contained, high-reliability, full-featured, SQL database engine.

## Installation

### Windows
1. Go to the [SQLite Download Page](https://sqlite.org/download.html).
2. Under "Precompiled Binaries for Windows", download the `sqlite-tools-win32-x86-*.zip` file.
3. Extract the ZIP file to a folder (e.g., `C:\sqlite`).
4. Add the folder path (`C:\sqlite`) to your System's `PATH` environment variable.
5. Open Command Prompt and type `sqlite3` to verify the installation.

### MacOS
SQLite is usually pre-installed on MacOS. You can check by opening the Terminal and typing `sqlite3`. 
If it's not installed, you can use Homebrew:
```bash
brew install sqlite
```

### Linux (Ubuntu/Debian)
Open your terminal and run:
```bash
sudo apt update
sudo apt install sqlite3
```
For other distributions, use your respective package manager (e.g., `yum install sqlite` on CentOS/RHEL or `pacman -S sqlite` on Arch).

## Running Your First Command Line with SQLite

1. Open your terminal or command prompt.
2. Start the SQLite shell by typing:
   ```bash
   sqlite3 my_first_db.db
   ```
   This will create a new file named `my_first_db.db` in your current directory and open the SQLite prompt.
3. You should see a prompt like `sqlite>`.
4. Type `.help` to see available meta-commands.
5. Let's create a simple table and insert a record:
   ```sql
   CREATE TABLE greetings (message TEXT);
   INSERT INTO greetings VALUES ('Hello, SQLite!');
   SELECT * FROM greetings;
   ```
6. To exit the SQLite shell, type:
   ```
   .exit
   ```
   or
   ```
   .quit
   ```
