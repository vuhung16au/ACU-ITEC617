ACU-ITEC617 SQL Injection Lab

This lab demonstrates the dangers of building SQL queries using string concatenation and how to prevent it.

Vulnerable Login

This endpoint constructs the SQL query unsafely:

SELECT * FROM app.users WHERE username = '$username' AND password = '$password'
Try this:
Username: ' OR '1'='1
Password: ' OR '1'='1

Secure Login

This endpoint uses parameterized queries to safely pass data:

SELECT * FROM app.users WHERE username = $1 AND password = $2
Try the same injection here. It will be safely interpreted as a literal string.

User Search (Vulnerable to UNION & Stacked Queries)

Search for a user by their username.

SELECT id, username, role FROM app.users WHERE username = '$username'
Try UNION Injection (extract secret data):
' UNION SELECT id, secret_name, secret_value FROM app.secret_data --

Try Stacked Query (destructive):
'; DROP TABLE app.secret_data; --
