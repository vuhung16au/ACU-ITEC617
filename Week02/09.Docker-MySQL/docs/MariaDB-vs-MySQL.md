# MariaDB vs MySQL

Both MariaDB and MySQL are popular relational database management systems that use SQL.

## MySQL
- **Background**: Originally created by MySQL AB, it was acquired by Sun Microsystems and later by Oracle Corporation.
- **Support**: Backed by Oracle, it has a strong enterprise presence.
- **Features**: Highly reliable and widely used, but some advanced features and proprietary plugins are reserved for the enterprise edition.

## MariaDB
- **Background**: Created as a fork of MySQL by its original developers after the Oracle acquisition, out of concerns over MySQL's future under Oracle.
- **Support**: Open source and community-driven, maintained by the MariaDB Foundation.
- **Features**: Designed as a drop-in replacement for MySQL. It is completely open source, typically includes newer features and storage engines faster, and often shows better performance for certain workloads. There are no enterprise-only locked features in the core server.
