# 01. Azure SQL Practice

This example project provides hands-on practice with Azure SQL, database provisioning, security, and read replica performance testing.

## Topics Covered
1. **Multi-Cloud Database Provisioning**: Using Azure CLI to create Azure Database for PostgreSQL, Azure SQL Database, and Azure Database for MySQL.
2. **Security & Access Control**: Configuring firewall rules, Azure Active Directory authentication, and Role-Based Access Control (RBAC).
3. **Read Replica Performance Testing**: Creating read replicas, simulating high-availability, and load distribution.
4. **Connection Tools & SQL Query Practice**: Connecting via different tools (psql, Azure Data Studio, pgAdmin) and writing progressively complex queries.

## Included Environment
A local Docker Compose environment is provided as a sandbox for SQL query practice and testing if Azure resources are not immediately available. It includes a PostgreSQL database and pgAdmin for seamless interaction.
