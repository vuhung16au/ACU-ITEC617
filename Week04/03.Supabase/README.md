# 03. Supabase Cloud Database Lab

## Enrichment Challenge: Supabase Cloud Database Lab
### Beyond Azure: Exploring Modern Database-as-a-Service (PaaS)

This example project provides an enrichment challenge exploring Supabase, an open-source Firebase alternative built on PostgreSQL.

## Why Supabase?
- **PostgreSQL-based**
- **CLI-first provisioning**
- **Row Level Security (RLS)**
- **AI SQL Assistant**
- **REST API auto-generation**
- **Real-time subscriptions**

## Lab Structure
1. **Provisioning with Supabase CLI**
2. **Schema Design & SQL Practice**
3. **Row Level Security (RLS) - Advanced RBAC**
4. **AI Assistant + Real-world Scenario**
5. **Bonus Challenge: Supabase CLI Deployment**
