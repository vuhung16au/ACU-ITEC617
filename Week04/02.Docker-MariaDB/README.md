# 02. Docker and MariaDB Lab

## Hands-On Lab: Cloud Database Simulation with Docker & MariaDB

### Objective
Simulate Azure cloud database provisioning and management locally using Docker containers, then practice SQL security and querying.

### Topics Covered
1. **Provisioning & Configuration**: Using Docker commands to "provision" a MariaDB database locally.
2. **Security & Access Control (RBAC Simulation)**: Creating users with different permission levels and testing their access.
3. **Database Population & SQL Querying**: Creating tables, inserting data, and running progressively complex SQL queries including JOINs and aggregations.

### Lab Deliverables
Students are expected to submit:
1. Screenshots of Docker commands and running container.
2. An SQL script file with all `CREATE USER`, `CREATE TABLE`, and query statements.
3. Test results demonstrating permissions (e.g., when a read-only user tries to `INSERT`).
4. Query outputs for all SQL challenges.
5. Evidence of cleanup commands execution.
