# Introduction to T-SQL (Transact-SQL)

**T-SQL (Transact-SQL)** is Microsoft SQL Server's proprietary extension of standard ANSI SQL. While standard SQL provides the fundamental commands for data manipulation (DML) and definition (DDL), T-SQL extends it with procedural programming capabilities, local variables, control-of-flow logic, and robust exception handling.

## Key Differences: T-SQL vs. Standard (ANSI) SQL

Here are some examples highlighting how T-SQL extends standard SQL:

### 1. Variables
*   **ANSI SQL:** Does not natively support procedural variable declaration in standard queries.
*   **T-SQL:** Uses the `DECLARE` statement and the `@` prefix for local variables.
    ```sql
    -- T-SQL Example
    DECLARE @EmployeeName VARCHAR(50);
    SET @EmployeeName = 'John Doe';
    
    SELECT @EmployeeName AS Employee;
    ```

### 2. Control Flow (IF/ELSE, WHILE)
*   **ANSI SQL:** Relies primarily on `CASE` statements for conditional logic within queries.
*   **T-SQL:** Provides robust control-of-flow constructs like `IF...ELSE`, `WHILE`, and `BEGIN...END`.
    ```sql
    -- T-SQL Example
    IF DATENAME(dw, GETDATE()) IN ('Saturday', 'Sunday')
        BEGIN
            PRINT 'It is the weekend!';
        END
    ELSE
        BEGIN
            PRINT 'It is a weekday.';
        END
    ```

### 3. Built-in Functions
*   **ANSI SQL:** Standardized basic functions (e.g., `CURRENT_DATE`, `EXTRACT()`, `COALESCE()`).
*   **T-SQL:** Offers rich proprietary functions (e.g., `GETDATE()`, `DATENAME()`, `ISNULL()`).
    ```sql
    -- T-SQL Example
    SELECT 
        GETDATE() AS CurrentDateTime,
        DATENAME(month, GETDATE()) AS CurrentMonthName,
        ISNULL(NULL, 'Default Value') AS NullHandling;
    ```

### 4. Data Types
*   **ANSI SQL:** Standard types like `VARCHAR`, `INTEGER`, `DATE`.
*   **T-SQL:** Introduces specific data types optimized for SQL Server, such as `VARCHAR(MAX)` (for up to 2GB of text), `DATETIME2`, and `UNIQUEIDENTIFIER`.
