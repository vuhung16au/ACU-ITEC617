# Theory: SQLite and Raw SQL

SQLite is a C-language library that implements a small, fast, self-contained, high-reliability, full-featured, SQL database engine. It is the most used database engine in the world. 

Using Raw SQL means writing the actual SQL query strings in your application code, rather than using an Object-Relational Mapper (ORM) to abstract the queries. This is useful for learning how SQL translates directly to application logic and allows for executing complex queries that might be difficult to express via an ORM.
