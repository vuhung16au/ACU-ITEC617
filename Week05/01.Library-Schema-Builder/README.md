# Library Database Schema Builder

This example demonstrates how to build a basic relational database schema for a library system using SQL Data Definition Language (DDL) and populate it using Data Manipulation Language (DML).

## Focus Areas
*   **DDL (Data Definition Language):** Writing `CREATE TABLE` statements with appropriate data types and constraints (Primary Keys, Foreign Keys).
*   **Table Alteration:** Using `ALTER TABLE` to modify an existing schema (e.g., adding an `ISBN` column to the `Books` table).
*   **DML (Data Manipulation Language):** Writing `INSERT` statements to populate tables with sample data.
*   **Referential Integrity:** Observing how foreign keys protect data integrity (e.g., attempting to `DROP` a table that is referenced by another table).
