# E-Commerce Product Query Challenge

This example provides a pre-populated `Products` table to practice basic and intermediate SQL querying techniques. 

## Focus Areas
*   **Basic Selection:** Using `SELECT` to retrieve specific columns.
*   **Filtering:** Using `WHERE` to filter records based on conditions (e.g., `< 50`).
*   **Computed Columns:** Calculating new values on the fly (e.g., discounted prices).
*   **Pattern Matching:** Using `LIKE` to find partial string matches.
*   **Ranges and Sets:** Using `BETWEEN` and `IN` for multiple values or ranges.
*   **Null Checks:** Finding missing or unknown data (`IS NULL`).
*   **Sorting:** Using `ORDER BY` for sorting results in ascending and descending order.
