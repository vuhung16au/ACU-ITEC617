# Student Enrollment JOIN Workshop

This example provides pre-populated `Students` and `Enrollments` tables to practice SQL JOIN operations.

## Focus Areas
*   **INNER JOIN:** Retrieving records that have matching values in both tables.
*   **LEFT OUTER JOIN:** Retrieving all records from the left table, and the matched records from the right table (useful for finding missing links, like students with no enrollments).
*   **RIGHT OUTER JOIN:** Retrieving all records from the right table, and the matched records from the left table.
*   **Aggregation with JOINs:** Using `GROUP BY` alongside JOINs to calculate metrics (e.g., average grade per student).
*   **HAVING Clause:** Filtering grouped results (e.g., students enrolled in more than 2 courses).
