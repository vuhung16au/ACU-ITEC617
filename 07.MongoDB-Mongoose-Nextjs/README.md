# 07.MongoDB-Mongoose-Nextjs

This project introduces NoSQL document databases using **MongoDB**. It demonstrates how to integrate MongoDB with a Next.js web application using **Mongoose** as an Object Data Modeling (ODM) library.

## Learning Objectives
- Understand the core concepts of NoSQL Document Stores.
- Learn when to use a document store versus a relational database.
- See how to connect to a MongoDB database from a Node.js (Next.js) backend.
- Understand how to model unstructured or semi-structured data with Mongoose schemas.
- Display data fetched from a database dynamically in a React frontend using Tailwind CSS.
